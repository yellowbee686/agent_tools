# agent_tools

- [`codex_usage`](codex_usage/README.md): view personal ChatGPT Codex token
  usage and API-equivalent cost estimates in a local dashboard or CLI.
- [`trace_tracker`](trace_tracker/README.md): browse local Codex and Claude Code
  traces, with reusable parsers for DeepSeek Harness.

With `uv` installed, start Trace Tracker from the repository root:

```bash
./run_trace_tracker.sh
```
