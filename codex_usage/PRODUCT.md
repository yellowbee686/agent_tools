# Product

## Register

product

## Users

A single technical user reviewing their own Codex token activity and estimating
what the same traffic would cost at OpenAI API token rates.

## Product Purpose

Turn the current personal ChatGPT account's daily Codex token buckets into a
fast local dashboard. Success means the user can select a date range, understand
usage shape and totals, inspect daily values, and see a transparent API-equivalent
cost estimate without managing credentials or relying on browser cookies.

## Brand Personality

Clear, professional, and candid. The interface should feel like a dependable
analysis instrument, with compact explanations where assumptions affect money.

## Anti-references

Avoid flashy trading dashboards, decorative gradients, neon developer-tool
themes, oversized vanity metrics, dense enterprise navigation, and any design
that presents an estimate as an exact bill.

## Design Principles

1. Put the selected period and its data shape before configuration details.
2. Expose every pricing assumption next to the resulting estimate.
3. Use familiar controls and readable data density for quick repeat visits.
4. Keep authentication invisible by reusing the current Codex login safely.
5. Distinguish measured token data from modeled cost data in language and style.

## Accessibility & Inclusion

No formal conformance target is required for this personal tool. Preserve basic
semantic HTML, keyboard-operable native controls, visible focus, and readable
contrast as normal product quality.
